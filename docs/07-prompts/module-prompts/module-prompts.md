# Per-Module Prompts
- **Auth Module:** Create FastAPI `/api/auth/login`, `/register`, `/me`, `/change-password` with bcrypt and JWT.
- **Courses & Batches Module:** Create course/module hierarchy and batch roster enrollment with capacity validation.
- **Assessments Module:** Create assignment submission/evaluation endpoints and timed MCQ quiz scoring.
- **Certificates & Payments Module:** Create fee installment tracker and ReportLab PDF certificate generator.

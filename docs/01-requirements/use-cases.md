# Use Cases & User Stories
## 1. Admin Stories
- **US-A01:** As an Admin, I can create/deactivate user accounts and assign roles so institute access stays controlled.
- **US-A02:** As an Admin, I can create courses, schedule batches with seat limits, and record student fee payments.
## 2. Instructor Stories
- **US-I01:** As an Instructor, I can upload lectures and study materials for my assigned courses.
- **US-I02:** As an Instructor, I can create assignments/quizzes, grade student submissions, and mark daily batch attendance.
## 3. Student Stories
- **US-S01:** As a Student, I can watch lectures, mark completion, attempt quizzes, submit assignments, and download my verified PDF certificate upon 100% completion.

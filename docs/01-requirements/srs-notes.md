# Requirement Analysis & SRS Notes
- **Document Version:** 1.1
- **Last Updated:** 2026-11-25
- **Objective:** Build a role-based Learning Management System (Admin, Instructor, Student) using React.js, Tailwind CSS, Python FastAPI, SQLAlchemy, MySQL, and JWT.
- **In-Scope:** RBAC authentication, course/module management, batches, lectures/materials, assignments/evaluations, timed MCQ quizzes with server-side grading, attendance tracking, progress calculation, PDF certificate generation & verification, fee receipts, notifications, and analytics exports.
- **Out-of-Scope:** AI automated grading, native mobile apps, built-in live video streaming server, biometric attendance.

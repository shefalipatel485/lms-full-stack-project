# System Architecture
- **Frontend:** React 18 + Vite + Tailwind CSS + Recharts + Axios (JWT Bearer interceptor).
- **Backend:** Python FastAPI + SQLAlchemy 2.0 ORM + Pydantic v2 + ReportLab (PDF certificates).
- **Database:** MySQL 8.0 (with SQLite zero-config fallback for instant local verification).
- **Folder Compliance:** Follows Section 9.1 (`frontend/src/...`) and Section 9.2 (`backend/app/...`) strictly.
